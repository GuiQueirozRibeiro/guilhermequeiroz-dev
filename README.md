# guilhermequeiroz.dev

Portfólio de **Guilherme Queiroz Ribeiro** — Engenheiro de Software (Mobile, Web & APIs).

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS · GSAP.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Conteúdo em `src/data/*.ts` (projetos, empresas, stack, destaques, serviços) e textos de interface em `src/i18n.tsx` (pt/en). Contatos e domínio em `src/lib/seo.ts`.

Base adaptada do portfólio de [Guilherme Rodrigues (@gui-ccr)](https://github.com/gui-ccr/portfolio-profissional).
